# Bootstrap Freelancer

The [Start Bootstrap](https://startbootstrap.com/theme/freelancer) "Freelancer" theme, which I assembled and studied while learning Bootstrap. It is not my own design: the theme and its license belong to Start Bootstrap.

**Live demo:** https://andreacassini.github.io/html-css-bootstrap-freelancer/

## What is in it

- One-page layout with navigation, portfolio, about and contact sections
- Contact form and footer

## Run

No build step. Open `index.html` in a browser.

Part of my portfolio: [https://andreacassini.com/projects/freelancer](https://andreacassini.com/projects/freelancer)
